## Retrospective
Raw exact identity is not necessarily database-resolved identity when a requested component is unquoted. Keep producer identity and SQL reference semantics distinct. Both priority and fallback need the same canonical-component restriction: fixing only precedence leaves canonical-absent wrong donors accepted. SQL include policy and connection database identity prevent blanket component folding; parser source prevents inappropriate Unicode casefold. Preserve these boundaries explicitly rather than claiming full PostgreSQL lexical equivalence.
